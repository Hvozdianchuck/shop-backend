# Returns

## Return window
You can return any product within 14 days of receiving it without giving a reason.
The 14 days start on the day you or the parcel locker received the parcel.

## Condition of returned items
Items must be complete, with all accessories and the original box. Signs of normal testing are fine.
If an item is damaged by use, we may reduce the refund by the loss of value.

## How to return
Contact support with your order number. We send a return label for InPost Paczkomat or DPD.
Pack the item and drop it off within 14 days of telling us about the return.

## Return shipping costs
Return shipping is free in Poland. From other countries the customer pays for return shipping.
If the item is faulty or we sent the wrong item, we always pay for return shipping.

## Refund time
We refund within 14 days of receiving the returned item, to the payment method used for the order.
BLIK and card refunds usually arrive within 3 working days after we send them. Shipping is refunded
only up to the cost of the cheapest delivery option.

## Items that cannot be returned
Software licence keys after they were revealed, and opened hygiene items such as in-ear headphones, cannot be returned.
